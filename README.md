# ClickTrauma

PWA de consulta rápida sobre **traumatismo em dentes decíduos**, com informações
baseadas em evidências para odontopediatras, cirurgiões-dentistas, professores e alunos.

Projeto vinculado à Faculdade de Odontologia da UERJ.

## Conteúdo

- Trauma em dentes decíduos
- Exame radiográfico
- Primeiro atendimento
- Diagnóstico e conduta clínica (11 fichas: fraturas, luxações, concussão, subluxação e avulsão)
- Possíveis alterações
- Como evitar

## Stack

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS 4

## Desenvolvimento

Instalar as dependências e subir o servidor local:

```bash
npm install
npm run dev
```

A aplicação fica disponível em `http://localhost:3000`.

## Build de produção

```bash
npm run build
npm start
```

## Qualidade

```bash
npm run lint
npm run format
```

## Repositório

Oficial: `teleodonto/ClickTrauma`
